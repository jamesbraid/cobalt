# cobalt coverage map

The areas of the Visual Workstation 320 and 540 graphics and where each stands. There is no measured inventory yet:
`retools/tools/inventory.py` needs the driver pack unpacked under `root/` and an inventory configuration. Until then the
rows below are the tally, graded as in [AGENTS.md](AGENTS.md).

| Area | State | Where |
|---|---|---|
| Display back end registers (Arsenic, `0xd0000000`) and mode table | graded from the Linux driver and the NT driver; cursor, gamma and capture blocks and every reset value unknown; no `registers.toml` yet | [devices/cobalt-graphics/display-engine.md](devices/cobalt-graphics/display-engine.md) |
| System firmware display set-up (PROM 1.0006 and 1.1005) | every register write of the console start-up in order, the mode record layout and both mode tables, the panel probe and flat-panel registers, the ID check, the `bist` self-test and the register read-back masks read from both images; reset values still unknown | [devices/cobalt-graphics/prom-init.md](devices/cobalt-graphics/prom-init.md) |
| Rendering engine window and packet queue | window extent, queue ownership bit, doorbell, the context switch and the stop interrupt read in full from the miniport (the `0x10000` start word, the buffer descriptor table, `0x185d0` and `0x18800` corrected); packet header word count field, chaining and link words read from the OpenGL driver; opcode set and window parameter and table packets in the packet-set page; most of the window unknown | [devices/cobalt-graphics/graphics-engine.md](devices/cobalt-graphics/graphics-engine.md) |
| Engine window register definitions | the registers a driver touches in the window directly (translation table, buffer descriptor table, start, doorbell, interrupt registers, scissor pair, chain registers, current-texture id, dump offset) and the payload words of the vendor's register-word types; every item inferred, no reset values | [devices/rendering-engine/registers.md](devices/rendering-engine/registers.md) |
| Rendering engine packet set | 52 constant header values of the OpenGL driver plus one of the display driver, classified with emitting routine and payload layout; the `B` field is the register index, the mode word, instance bits, vertex ports, window parameters and table entries are decoded as the drivers write them; the payload words named from the vendor's own bit-field types and compared with every writer; texture-coordinate generation is always the host's; engine behaviour unknown | [devices/cobalt-graphics/packet-set.md](devices/cobalt-graphics/packet-set.md), [draw-and-buffers.md](devices/cobalt-graphics/draw-and-buffers.md) |
| SGI white paper and a real machine's registry | read in full; features, identity, resource claims and memory ranges recorded | [devices/cobalt-graphics/board-data.md](devices/cobalt-graphics/board-data.md) |
| NT 4.0 OpenGL driver structure | symbols from the `.dbg` COFF table (counts reproduced) and the program database's type declarations (context, vertex record, window record; the NT 4.0 and Windows 2000 layouts identical); run-time code generators identified; header scan done on the NT 4.0 and Windows 2000 packs and the April 1999 build (50 of the 52 base headers, nothing outside the set; its 31 escape call sites read); engine-versus-host rules for transform and lighting read | [software/windows/nt-opengl-icd.md](software/windows/nt-opengl-icd.md) |
| NT 4.0 miniport, display and OpenGL drivers | miniport attach, display back end programming and the OpenGL escape table read; the OpenGL driver's packet emitters classified in the packet-set page (the engine's use of them is unknown) | [devices/cobalt-graphics/nt-software.md](devices/cobalt-graphics/nt-software.md) |
| Windows 2000 boot video and frame buffer drivers | read in Ghidra, no symbols | [software/windows/w2k-display-drivers.md](software/windows/w2k-display-drivers.md) |
| Regrading to three ratings | done by mapping in round 2 (software expectation and observed became inferred, with the narrow established cases kept); rows not re-read | [devices/cobalt-graphics/README.md](devices/cobalt-graphics/README.md#grades) |
| Open questions | the packet set, engine window, second interrupt register, reset values, cursor and capture | [questions/open-questions.md](questions/open-questions.md) |
